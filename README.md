# Mid-Market Sellers · GitHub Copilot Hands-On Workshop

A **90-minute** hands-on workshop for **Mid-Market Account Executives and Sellers** with limited GitHub Copilot exposure. Everyone does the same two live modules together: a guided GitHub App setup, then a deep-dive on generating customer-ready slide decks with Copilot. Five additional modules go home as self-study.

> **Goal:** By the end of the session, every seller has personally generated a customer-ready deck with Copilot they can use Monday — and can speak fluently about the **June 1, 2026 transition to usage-based billing** (GitHub AI Credits) using firsthand experience.

---

## Stage 1 · Live Setup (~25 min)

Everyone in the room completes this together so we share a baseline.

| # | Module | What you'll do |
|---|---|---|
| 1 | [GitHub App: Setup & First Look](modules/01-github-app-setup.md) | Install, sign in, enable experimental flags, tour the surfaces, run a smoke-test prompt |

## Stage 2 · Live Deep-Dive (~60 min, debrief embedded)

Everyone runs the same module. You'll pick one of four **deck types** when you get there.

| # | Module | What you'll build |
|---|---|---|
| 2 | [Slide Deck Maker](modules/02-slide-deck-maker.md) | Generate a customer-ready deck — pick from Customer Q&A, GitHub Docs summary, EBC deep-dive, or Pricing transition |

## Stage 3 · Take-Home Self-Study

Same depth, same playbook framing. Run on your own time after the workshop.

| # | Module | What you'll do | Best fit if… |

## The Commercial Throughline

Module 2 lasers in on the **non-developer / seat-expansion** story: Copilot reaches PMs, sellers, and marketing — same SKU your devs already have. The heavier agentic stories (Cart Page → Agent Merge, vibe-coded games, grounded account research) live in the take-home modules. Every module — live and take-home — ends with a **Seller Playbook** mapping the hands-on activity to:

- **Agentic vs. chat usage** — why some sessions burn 100× the tokens of others
- **Premium Requests** (legacy, through annual plan expiration)
- **GitHub AI Credits & Usage-Based Billing** (effective June 1, 2026)
- A customer talk track + objection handler
- An expansion play (which SKU to position, when to upsell credits)
