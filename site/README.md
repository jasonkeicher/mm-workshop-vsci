# Workshop Site (Starlight + Astro)

Static documentation site for the Mid-Market Seller Copilot Workshop, mirroring the look and structure of `demo-docs`.

## Source of truth

The authoritative markdown lives **at the repo root** (`../README.md`, `../prerequisites.md`, `../seller-playbook-overview.md`, `../facilitator-guide.md`, `../modules/*.md`).

This site is generated by copying those files into [src/content/docs/](src/content/docs/) with Starlight-compatible frontmatter.

**Edit the originals at the repo root, then re-sync:**

```powershell
npm run sync
```

## Develop

```powershell
npm install
npm run sync
npm run dev
```

Then open <http://localhost:4321>.

## Build

```powershell
npm run build
npm run preview
```

Static output lands in `dist/`. Deploy that folder to any static host (GitHub Pages, Cloudflare Pages, Azure Static Web Apps, etc.).

## Layout

```
site/
├── astro.config.mjs           # Starlight config + sidebar
├── package.json
├── tsconfig.json
├── scripts/
│   └── sync-content.ps1       # Copies root markdown -> content collection
└── src/
    ├── content.config.ts      # Starlight content collection schema
    └── content/docs/
        ├── index.md
        ├── prerequisites.md
        ├── seller-playbook-overview.md
        ├── facilitator-guide.md
        └── modules/01..06-*.md
```
